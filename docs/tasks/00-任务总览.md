# 矿山智工 · 升级任务总览

> 用法：**每次只把一个任务文件（01~15）的内容发给执行 AI**，做完验收后再发下一个。
> 任务按依赖排序，编号即推荐执行顺序。每个任务自包含背景/改动/验收，无需阅读本文档以外的规划文档。

## 项目速览（所有任务共用背景）

- **项目**：矿山智工（`D:\徐工`）——全离线矿山工程机械运维 AI 工作台，参赛「中国创新创业大赛 AI+工程机械专业赛」。
- **技术栈**：Vue 3 + Element Plus + Pinia + Vue Router + ECharts（渲染层）；Electron（contextIsolation + sandbox + preload 白名单，主进程）；sql.js（本地 SQLite，Electron 落盘 `userData/*.db`，浏览器走 IndexedDB）；node-llama-cpp + Qwen2.5-0.5B（本地叙述模型）。
- **目录要点**：`src/main/`（Electron 主进程+LLM 引擎）、`src/preload/`（contextBridge 白名单）、`src/renderer/src/`（views 15 页 / components / stores（appStore 主状态）/ utils（health、nlCommand、knowledgeBase、database 等）/ styles（tokens.css））、`scripts/`（验收脚本）、`resources/models/`（本地模型，不随 git 分发）。
- **三条铁律（任何修改不得破坏）**：
  1. 运行期零联网、无任何云端 API key（`src/` 内无对外网络请求）；
  2. 数据不出本机（Electron 落 userData，浏览器走 IndexedDB）；
  3. 数字不变量校验：大模型生成文本中的数字必须 ⊆ 规则引擎结论的数字集合（`utils/llmClient.js` 的 `verifyNumbersSubset`），失败静默回退规则引擎原文。
- **验收命令**：`npm run verify` = lint + self-check(288 断言) + coverage + build + e2e(88) + e2e:nl(28) + contrast-audit(16 路由)。每个任务完成后至少跑相关部分，改动到业务逻辑必须跑全量 verify。
- **不动清单**：`utils/health.js`（健康评分）、`utils/nlCommand.js`（口述解析核心）、`utils/llmClient.js`（数字不变量校验）、`utils/database.js`（数据库层）——只增不改。
- **已知状态**：lint 0 错 0 警 / self-check 288 通过 / e2e 88 通过 / e2e:nl 28 通过 / 对比度 16 路由全达标 / 生产构建成功（但 vendor-element chunk 974KB 超 700KB 阈值）。npm audit 因镜像源不支持无法执行。

# 任务 10：数据大屏模式（/big-screen 全屏看板）

## 背景

- 现状：`src/renderer/src/views/Dashboard.vue`（44KB）是常规工作台看板，无全屏/演示形态。
- 目标：一键进入**全屏无干扰看板**（暗底、大字号、核心指标），演示与汇报场景的"第一眼"。依赖任务 09 深色主题（大屏复用暗底）。
- 复用资产：`components/AnimatedNumber.vue`（数字滚动）、Dashboard 现有的健康分布 SVG 饼图、`components/TrendChart.vue`（ECharts）、store 的计算属性（`stats/healthLevelStats/criticalList/overdueList/faultTopStats`）。

## 目标

1. 新路由 `/big-screen`：全屏暗底看板，30 秒自动刷新数据，Esc / 按钮退出；
2. Dashboard 右上角「进入大屏」入口；
3. 引导演示可加入"大屏线"步骤（本任务只预留入口，路线编排在任务 14）。

## 改动清单

| 文件 | 动作 | 说明 |
|------|------|------|
| `src/renderer/src/views/BigScreen.vue`（新增） | 大屏页 | 布局 + 数据 + 刷新 + 退出 |
| `src/renderer/src/router/index.js` | 注册路由 | `/big-screen`（懒加载） |
| `src/renderer/src/views/Dashboard.vue` | 加入口按钮 | 「进入大屏」 |
| `src/renderer/src/styles/`（tokens.css 或新增 bigscreen.css） | 大屏样式 | 暗底、大字号（用任务 09 的深色令牌） |

## 实现要点

- **布局**（全屏 16:9 自适应，窗口缩放重排）：
  - 顶部横幅：设备总数 / 运行率 / 健康 A-B-C-D 分布 / 预计停机损失（大字号，`AnimatedNumber`）；
  - 中部：健康等级分布 SVG 饼图放大 + D 级设备滚动列表（红色预警）+ 7 日告警/维保趋势（ECharts）；
  - 底部：超期 TOP 设备横向滚动条或表格。
- **数据刷新**：`setInterval` 30s 重算 store 计算属性（响应式自动更新）；页面 `onUnmounted` 清理定时器。
- **全屏**：`document.documentElement.requestFullscreen()`（可选，失败不阻塞，页面本身铺满即可）+ 路由全屏布局（隐藏侧边栏）。
- **退出**：Esc 键监听 + 右下角悬浮「退出大屏」按钮；退出时清理全屏与定时器。
- **降级**：浏览器模式同样可用（不依赖 Electron API）；ECharts 加载失败时其余数字照常显示。

## 验收标准

1. `/big-screen` 可进入/退出（Esc 与按钮均有效），侧边栏隐藏、全屏铺满；
2. 核心指标数字正确且与 Dashboard 同源（同一批 store 计算属性，不另算一套）；
3. 30 秒刷新生效（可临时改小间隔验证）；
4. 深色/大屏下对比度可读；
5. `npm run lint` 0 错；`npm run e2e` 全过（新增路由可加一条 e2e：进入大屏→断言关键数字存在→退出）。

## 注意

- 大屏**只读**，不提供任何操作按钮（演示场景防误触）。
- 不新增数据逻辑：全部复用 store 计算属性与现有图表组件。
- 图标/数字样式与项目视觉规范一致，不引入新设计语言。

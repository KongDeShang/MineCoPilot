# 任务 13：报告导出增强（周报 / 月报 + HTML/PDF/CSV）

## 背景

- 现状：`src/renderer/src/utils/reportGenerator.js`（11.5KB）已实现**单设备体检报告**（健康分因子拆解、算式溯源，配合 `styles/healthReport.css`）；有打印友好的基础。
- 目标：扩展到**设备群月报 / 运维周报**，输出 HTML（浏览器打印成 PDF）/ CSV 三种格式；报告延续"每个数字带来源"的可审计叙事。
- 依赖：任务 08 docService（本任务主要复用解析链做"报告数据导出"，如非必要不强依赖；CSV 导出用现有 SheetJS 能力）。

## 目标

1. 新增报告类型：设备群月报（健康分布变化/超期清单/工单完成率/备件消耗 TOP/停机损失统计）、运维周报（本周新增告警/工单/复诊/经验沉淀）；
2. 体检报告补"趋势对比"段（本次 vs 上次快照）；
3. 输出：HTML 报告（打印版式→浏览器打印 PDF）+ CSV 明细导出；
4. 每个统计数字旁标注数据来源（规则引擎实时计算 / 工单表归档 / 备件流水）。

## 实现要点

- **数据口径**（全部现算，从 store 读，不写死）：
  - 月报：当月工单完成率、健康分档分布（当月 vs 上月）、超期 TOP10、备件消耗 TOP（`partTransactions` 聚合）、停机损失合计（`health.js` 的停机估算）；
  - 周报：本周新增告警/工单/复诊完成/知识沉淀数量 + 明细清单。
- **来源标注**：HTML 报告里每个统计块带 `<span class="src">数据来源：…</span>`；CSV 首行注释列说明口径。
- **打印为 PDF**：预览弹窗用 `window.print()` + `@media print` 版式（项目已有 healthReport.css 的打印经验，扩展即可）；**不引重量级 PDF 库**（中文渲染风险与体积权衡）。
- **CSV**：用现有 SheetJS（任务 04 后版本）`XLSX.utils.json_to_sheet` 或手写 CSV 转义（字段含逗号/引号要转义，中文用 UTF-8 BOM 保证 Excel 打开不乱码）。
- **报告页结构**：页眉（标题+生成时间+范围）、正文（指标卡+表格+趋势简述）、尾页签名区（负责人/日期，打印后手签）。
- 复用现有 HTML 转义 `utils/html.js`（项目已统一转义入口，别另写）。

## 验收标准

1. 周报/月报可生成预览，数字与看板/列表同源一致（抽 3-5 个数字人工核对）；
2. 打印预览版式正确（分页合理、页眉页脚、签名区）；浏览器打印可存 PDF；
3. CSV 导出可用，Excel 打开中文不乱码；
4. 体检报告趋势对比段正常（两次快照对比，无快照时显示"无历史"）；
5. `npm run verify` 全绿（含新增自检断言）。

## 注意

- 报告**只读**，不触发任何写库操作；
- 数据全部来自规则引擎/store 现算，禁止硬编码示例数字（铁律 3）；
- 打印版式先桌面 A4 即可，不做多纸张适配。

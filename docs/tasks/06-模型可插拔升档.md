# 任务 06：模型可插拔升档（ModelRegistry + 能力分级）

## 背景

- 现状：`src/main/llmEngine.js` 写死单一模型——`MODEL_FILE = 'qwen2.5-0.5b-instruct-q4_k_m.gguf'`、`MODEL_DISPLAY = 'Qwen2.5-0.5B-Instruct（本地内置）'`、`modelDir()` 固定 `resources/models/qwen2.5-0.5b/`；加载/生成/状态机（idle→loading→ready/failed→generating）已实现且质量高（懒加载、AbortController 取消、失败回退、装机自检 `runSelfVerify`）。
- 目标：模型成为**可切换服务**——多档位注册表 + 按硬件自动选档 + 能力分级（档位不够的功能入口自动隐藏）+ 切档懒加载/释放。
- 铁律不变：任何档位生成文本必须过渲染端 `verifyNumbersSubset` 数字不变量校验；模型仍只在主进程跑；完全离线（`skipDownload: true`，禁止 node-llama-cpp 联网下载二进制）。

## 目标

1. `ModelRegistry.js`：档位元数据（id/名称/文件/体积/最低内存/能力列表），启动自动选档（探测系统内存 + 可选实测推理速度）；
2. `ModelSession.js`：单档加载/生成/释放，切档先释放旧 session；
3. `llmEngine.js` 改造为使用注册表与会话管理，保留现有 IPC 状态机；
4. `preload` 增加 `llm.listModels` / `llm.switchModel`；
5. `ModelHub.vue` 升级为「模型中心」：当前档位、可用档位列表、切换、自检报告展示。

| 文件 | 动作 | 说明 |

| `src/renderer/src/utils/llmClient.js` | 增加客户端方法 | `llmListModels()` / `llmSwitchModel(id)`，保持浏览器模式降级 |

## 实现要点

- **档位定义**（Q4_K_M 量化，体积为估算，以实际文件为准）：
  | 档位 | 模型 | 体积 | 最低内存 | 能力 |
  |------|------|------|---------|------|
  | light（默认） | Qwen2.5-0.5B-Instruct（现有） | 468MB | 任意 | narrate（叙述润色） |
  | standard | Qwen2.5-1.7B / Qwen3-1.7B | ~1.1GB | 8GB | narrate + diagnose + summarize |
  | enhanced | Qwen3-4B | ~2.5GB | 16GB | + 复杂推演 |
  - 模型文件可能不在本地（分发方案见任务 07）——注册表要区分「已安装 / 未安装」，未安装档位在 UI 显示"待下载/待放入"。
- **自动选档**：主进程探测（`os.totalmem()`），8GB 以下选 light，8-16GB 选 standard，16GB 以上选 enhanced；结果可被手动切换覆盖并持久化（写 `userData` 下的配置文件或通过 IPC 告知渲染层存 meta）。
- **能力分级**：`capabilities` 数组声明；渲染层根据当前档位能力决定功能入口显隐（如 diagnose 相关入口只在 standard+ 显示）——本任务先定义能力模型，入口灰度的具体页面改造跟随对应功能任务。
- **释放语义**：`switchModel` 时先 `context?.release?.()` / 置空 model/context/completion，再加载新档；切换失败回退原档，状态机保持可观测。
- 数字不变量校验逻辑不动（在 llmClient.js），任何档位输出路径一致。
- 注意 node-llama-cpp 是 ESM-only，主进程必须用动态 `import()`（现状已如此，保持）。

## 验收标准

1. `npm run lint` 0 错；`npm run self-check` 288 通过（可加 1-2 条注册表断言：档位元数据完整、自动选档在 mock 内存下返回预期档）；
2. Electron 开发模式（`npm run electron:dev`，需本地有模型文件）：`llm.listModels` 返回档位与"已安装"状态；当前档位可加载生成；`llm.switchModel` 切到未安装档位返回明确错误且不破坏当前会话；
3. `ModelHub.vue` 显示档位卡片/切换/自检，功能可用；
4. 浏览器模式（`npm run dev`）降级正常（`unavailable`）；
5. 装机自检 `KUANGSHAN_LLM_VERIFY=1` 仍可用。

# 任务 16：数据备份与迁移一键化（换机导出 .mbak → 导入恢复）

> 状态：✅ 已完成（2026-09-16，提交 `795bf66`）——含文档/设置纳入 v2、SHA-256 校验、导入前自动备份；e2e 96/96 含 4 条备份断言。

## 背景

- 现状：项目已有备份雏形（`utils/backup.js` v1 + `backup:export/import` IPC + 设置页备份卡），但**有潜伏 bug 与范围缺口**：
  1. **preload 潜伏 bug**：`backup` 挂在 `app` 子级，而 backup.js 的 `isElectron()` 检查顶层 `window.electronAPI.backup` → Electron 模式下恒为 false → **导出降级成 Blob 下载、导入路径从未启用**（真机从未验证过）。
  2. **范围缺口**：v1 只含数据库 + AI 聊天记录，**不含**文档资料库文件（`userData/documents/`）与用户设置（主题/色彩/向导/导航钉住）。
  3. 无完整性校验：备份文件损坏/半截/被改无法识别，导入后数据静默损坏。
  4. 无防呆：导入直接覆盖当前数据，错了无法回滚。
- 目标：**一键换机**——旧电脑导出单个 `.mbak` → 新电脑导入恢复，覆盖整库 + 聊天记录 + 设置 + 文档文件，带 SHA-256 完整性校验 + 导入前自动备份（可回滚）。
- 用户拍板：备份迁移优先于「AI 老师傅人设」（Batch B 后续再做）。

## 目标

1. 备份内容 = 数据库 + AI 聊天记录 + 用户设置（白名单键）+ 文档资料库文件；
2. `.mbak` 单文件（UTF-8 JSON），v2 带 `sha256` 完整性校验，兼容 v1 旧备份导入；
3. 导入前自动备份当前数据到 `userData/backups/`（静默、不弹框），导入后提示路径可回滚；
4. Electron 真机路径可用（修复 isElectron bug），浏览器模式降级 Blob 下载/导入需外部传内容。

## 实现要点

- **SHA 口径**（防篡改/损坏）：`sha256 = sha256Hex(dbBase64 + '|' + JSON.stringify({ chatHistory, settings, docFiles }))`，字段放在 JSON 内；校验时重算比对，不一致拒绝导入并报"完整性校验失败"。
- **文档文件双模式**：Electron 主进程 `docs:readAll` 读 `userData/documents/`（带体积上限，超限**点名报错**而非静默截断）；浏览器模式读 IndexedDB `kuangshan-docs`（store `files`，键 `doc:<name>`），恢复时 `clear` 后写回。
- **设置白名单**：只迁移用户设置类键（主题/色彩/向导/导航），不碰数据库兜底键，避免跨机恢复把本地库状态带乱。
- **自动备份防呆**：`importBackup` 在 Electron 模式下、弹打开框**之前**先 `exportBackup({auto:true})` 静默写 `userData/backups/`；失败不阻断导入（console.warn）。成功后把路径随返回值给 UI 提示。
- **版本兼容**：`version` major ∈ [1,2]；v1 无 `sha256`/`settings`/`docFiles` 按兼容处理（跳过校验与缺省恢复）。
- **e2e 已知缺口**：Electron 弹框（导出保存框/导入打开框）无法 headless 自动化 → 测试在浏览器模式动态 `import('/src/utils/backup.js')` 直调 `buildBackup`/`importBackup` 验证逻辑；Electron 真机弹框路径需人工验证（见遗留）。

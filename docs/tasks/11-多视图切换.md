# 任务 11：多视图切换（ViewSwitcher 四视图）

## 背景

- 现状：设备台账（`views/Equipment.vue`）、工单管理（`views/WorkOrder.vue`）、备件库存（`views/PartsInventory.vue`）都是固定 `el-table` 列表形态，无视图切换能力。
- 目标：同一数据集支持**列表 / 卡片 / 图表 / 时间线**四种视图，通用切换组件，偏好持久化。
- 复用资产：现有表格保持为"列表"视图；`views/Dashboard.vue` 的"重点关注设备"卡片样式可提炼为通用卡片；`components/TrendChart.vue` 用于图表视图；时间线用 Element Plus `el-timeline`。

## 目标

1. `components/ViewSwitcher.vue` 通用组件（四个图标切换 + `v-model`）；
2. 四种视图渲染组件（列表复用现有表格、卡片网格、图表概览、时间线）；
3. 首批接入三页：设备台账 / 工单管理 / 备件库存；视图偏好 localStorage 持久化。

## 改动清单

| 文件 | 动作 | 说明 |
|------|------|------|
| `src/renderer/src/components/ViewSwitcher.vue`（新增） | 切换器 | 列表/卡片/图表/时间线四图标，emit `update:modelValue` |
| `src/renderer/src/components/views/ListView.vue`（新增） | 列表渲染器 | 包装 el-table（或直接由页面保留现有表格） |
| `src/renderer/src/components/views/CardGridView.vue`（新增） | 卡片渲染器 | 网格卡片（提炼 Dashboard 卡片样式为通用组件） |

| `src/renderer/src/components/views/TimelineView.vue`（新增） | 时间线渲染器 | el-timeline 按时间字段排序 |
| `src/renderer/src/views/Equipment.vue` | 接入 | 列表+卡片+时间线 |
| `src/renderer/src/views/WorkOrder.vue` | 接入 | 列表+时间线+图表 |
| `src/renderer/src/views/PartsInventory.vue` | 接入 | 列表+卡片 |

## 实现要点

- **数据契约**：每个页面把数据归一化为 `{ id, title, subtitle, status, time, extra[] }` 数组喂给渲染器——渲染器不感知业务字段，页面负责映射（视图组件与业务解耦，后续新域复用）。
- **卡片渲染器**：从 Dashboard"重点关注设备"卡片样式提炼（照片/等级徽标/名称/元信息），支持 `cover`（设备照片）与 `avatar`（图标）两种模式。
- **图表渲染器**：默认按分类/状态聚合出柱状或环形图（复用 TrendChart 的按需 echarts 加载模式），无数据时显示空态。
- **时间线渲染器**：按 `time` 降序，节点带状态色点与标题/描述，可点击跳详情（由页面注入点击回调）。
- **持久化**：`localStorage` key `view-pref:<route-name>`；切换即存。
- 三个页面的**列表视图必须保持现状**（表格列、操作按钮、分页原样），只新增切换入口。

## 验收标准

1. 三页均可四视图切换（或按任务说明的视图子集），切换即时生效、无布局错乱；
2. 刷新页面后视图偏好保持；
3. 列表视图与升级前逐项一致（列/操作/分页）；
4. 卡片/图表/时间线数据与列表同源（同一 store 数据，不另算）；
5. `npm run lint` 0 错；`npm run e2e` 全过（原有列表断言不回归；可加 1-2 条视图切换 e2e）。

## 注意

- 渲染器组件保持**业务无关**；页面负责字段映射，避免后续新域复制视图代码。
- 图表视图只在有数据的字段上聚合，别为"空数据"硬造图表。
- 不动 health.js / nlCommand.js / llmClient.js / database.js。

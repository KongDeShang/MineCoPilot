# 任务 07：模型云端分发（modelManager + 首次向导 + 双轨打包）

## 背景

- 现状：安装包体积 **627MB**，其中模型（`resources/models/qwen2.5-0.5b/`，468MB GGUF）随包内置（electron-builder `extraResources` 复制到 resources/models）。
- 决策（已确认）：模型从安装包拿出放云端，**用户首次安装时一键选择、自动下载嵌入本地，此后完全离线**（"一次联网，永久离线"）。
- 依赖：任务 06 的 `ModelRegistry`（本任务复用其档位定义与"已安装/未安装"状态；双源扫描 `resources/models` + `userData/models` 在本任务落地）。
- 关键设计（来自升级规划）：
  - **云端存放决策（已确认，2026-09-15：GitHub Releases 为主源）**：
    - 存储方案：GitHub Releases 免费、无期限、URL 稳定、上传简单（网页拖拽或 `gh release upload`）；模型为 Qwen（Apache-2.0），公开分发无合规问题；"开源平台分发"对评委叙事更顺。
    - **硬限制（必须处理）**：GitHub Releases 单文件上限 **2GB** → **4B 档（~2.5GB）放不下**。处理：赛前只上两档——light（0.5B，468MB）+ standard（1.7B，~1.1GB）；enhanced（4B）在 ModelRegistry 保留定义但 `available: false` 标注"待扩展"，向导与模型中心不展示为可下载（能力分级逻辑照常，只是该档无源）。
    - **下载链路注意**：`https://github.com/<owner>/<repo>/releases/download/<tag>/<file>` 会 302 重定向到 `objects.githubusercontent.com`（签名 CDN）。下载器必须跟随重定向且**保留 Range 头**（见实现要点"302 重定向"）。重定向后的 CDN 支持 Range（返回 206）。
    - **大陆访问**：GitHub 下载在大陆速度不稳、可能中断——对"一次性安装时下载"可接受（配合断点续传 + 失败重试），但答辩口径措辞为"模型托管于 GitHub Releases 开源分发，下载后完全离线"；不要现场演示下载环节。可选：第三方加速镜像（如 ghproxy 类）作为备用 URL，但不作正式依赖（第三方稳定性不可控）。
    - 落地步骤（**模型上传由执行 AI 完成**，2026-09-15 已验证）：
      - **仓库与网络（已验证）**：仓库 `https://github.com/KongDeShang/MineCoPilot` 存在（HTTP 200）；本机经 Clash Verge 代理 `127.0.0.1:7897` 可访问 GitHub，但 curl 需加 `--ssl-no-revoke`（Windows Schannel 吊销检查会失败，CRYPT_E_NO_REVOCATION_CHECK）；gh CLI 若连不上需设 `$env:HTTPS_PROXY="http://127.0.0.1:7897"`。
      - **上传模型**（模型文件在 `D:\徐工\resources\models\`，标准档 1.7B 若本地缺失则先仅传 0.5B，或从 HuggingFace 下载 Qwen2.5-1.7B-Instruct Q4_K_M GGUF 后再传）：创建 Release tag `models-v1.0.0`，上传两个 GGUF 资产。方式 A（gh CLI）：`gh release create models-v1.0.0 --repo KongDeShang/MineCoPilot` 后 `gh release upload models-v1.0.0 <file> --repo KongDeShang/MineCoPilot`；方式 B（curl+API）：用 PAT 调 `POST /repos/KongDeShang/MineCoPilot/releases` 建 release，再用返回的 upload_url `POST ...?name=<file>`（Content-Type: application/octet-stream）传资产。

      - **models.json 结构**（URL 已确定，SHA/sizeBytes 上传后填实际值）：

  - **双轨打包**：A 在线安装包（不含模型，~150MB，主推）；B 完整离线包（内置 0.5B，~627MB，兜底给无网场景）。
  - 首次启动：检测无本地模型 → 弹「模型选择向导」→ 按内存推荐档位 → 一键下载 → SHA-256 校验 → 落 `userData/models` → 自动跑装机自检（复用 `runSelfVerify`）→ "模型已就绪，可断网使用"。

5. 无模型时启动不阻塞（AI 功能显示"未就绪"，主流程照常）。

## 实现要点

- **断点续传**：用 `https` 模块 + `Range: bytes=`，`.part` 文件存进度；恢复时从已下字节续传；下载完成改名并校验 SHA-256，不符删 `.part` 报错可重试。
- **302 重定向（GitHub Releases 必须）**：`releases/download/` URL 会 302 → `objects.githubusercontent.com`。下载器实现要点：① 首次请求不带 Range 跟随重定向，记录最终 URL 与 `accept-ranges`；② 对最终 URL 发 `Range: bytes=<已下>-` 续传；③ 重定向目标 URL 带签名有有效期，若续传时过期（403），重新走一遍 ① 拿新最终 URL 再续；④ 超时/中断自动重试（最多 3 次，指数退避）。不要直接把 objects.githubusercontent.com 的签名 URL 写进 models.json（会过期）。
- **进度推送**：`event.sender.send('models:progress', { id, received, total, pct })`；渲染层节流更新 UI。
- **双源扫描**：`resources/models`（只读）+ `userData/models`（可写）；manifest.json 在 userData/models 登记已下载档位（版本/哈希/时间）；扫描时两处合并，冲突以 userData 为准（用户后来下载的更新）。
- **无模型降级**：`llm:status` 在无已装模型时返回 `state:'unavailable'` 或明确 `error:'未安装模型'`；渲染层 AI 叙述自动回退模板（现有降级链已支持，保持）。
- **向导触发**：`initStore` 后检测 `!registry.hasInstalled()` 且非 Electron 打包环境跳过；向导可"跳过"，稍后在模型中心装。
- **清单 URL 配置**：`models.json` 的 URL 做成数组（主源 + 备用镜像）；manifest 拉取失败 → 界面显示"离线，仅显示已装模型"。
- **打包**：electron-builder `extraResources` 条件化——提供 `npm run electron:build:online`（去掉 models）与 `electron:build:offline`（保留）。模型文件路径在打包配置里引用 `resources/models`。
- 铁律：下载只发生在**用户明确点击下载时**（一次性）；运行期无任何自动联网拉取（清单可启动时静默拉取但失败不阻塞、不重试轰炸——或做成仅向导/模型中心页面手动刷新）。

## 验收标准

1. 在线安装包构建成功，安装后体积 ~150MB 量级；无模型可正常进入工作台，AI 功能显示"未就绪/降级"；
2. 向导：选择档位 → 下载（进度显示）→ 校验 → 自检 → "可断网使用"；中途关应用再开可续传；
3. 断网后模型可用（加载/生成/自检正常）；
4. 模型中心：下载、删除（释放空间）、切换档位均正常；`llm-verify.json` 自检报告可展示；
5. 离线包（B）构建后内置 0.5B 开箱即用，不弹向导；
6. 4B 档在模型中心显示"待扩展/不可下载"，不报错不卡界面；
7. `npm run verify` 全绿（e2e 需适配：无模型环境下 AI 相关断言按降级路径断言）。

## 注意

- 下载源：**由执行 AI 上传模型到 `https://github.com/KongDeShang/MineCoPilot/releases/download/models-v1.0.0/` 后填入**（仓库与代理已验证，见背景落地步骤；代理 127.0.0.1:7897，curl 需 --ssl-no-revoke）。4B 档因 2GB 上限不在赛前上线，models.json 中标注 unavailable。未上传前先用占位 URL + 注释说明，**不要伪造真实 URL / 不要编造 SHA-256**（SHA 必须来自 `Get-FileHash` 实测）。
- 不要在用户未确认时自动下载模型（隐私/流量）；一切以用户点击为准。
- 若 e2e 环境无模型文件，AI 相关 e2e 按现有降级路径跑，不要为过测试而改断言口径。

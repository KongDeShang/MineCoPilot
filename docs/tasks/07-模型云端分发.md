# 任务 07：模型云端分发（modelManager + 首次向导 + 双轨打包）

## 背景

- 现状：安装包体积 **627MB**，其中模型（`resources/models/qwen2.5-0.5b/`，468MB GGUF）随包内置（electron-builder `extraResources` 复制到 resources/models）。
- 决策（已确认）：模型从安装包拿出放云端，**用户首次安装时一键选择、自动下载嵌入本地，此后完全离线**（"一次联网，永久离线"）。
- 依赖：任务 06 的 `ModelRegistry`（本任务复用其档位定义与"已安装/未安装"状态；双源扫描 `resources/models` + `userData/models` 在本任务落地）。
- 关键设计（来自升级规划）：
  - **双轨打包**：A 在线安装包（不含模型，~150MB，主推）；B 完整离线包（内置 0.5B，~627MB，兜底给无网场景）。
  - 首次启动：检测无本地模型 → 弹「模型选择向导」→ 按内存推荐档位 → 一键下载 → SHA-256 校验 → 落 `userData/models` → 自动跑装机自检（复用 `runSelfVerify`）→ "模型已就绪，可断网使用"。
  - 下载管理器：HTTP Range 断点续传、进度事件、失败不阻塞主流程（AI 降级规则引擎）、可删除模型释放空间、多镜像。
  - 云端清单 `models.json`：id/名称/档位/体积/所需内存/能力/SHA-256/版本/URL 列表/许可声明（Qwen 为 Apache-2.0 可再分发）。
  - 答辩口径："安装包轻量化到 1/4；模型是一次性可选下载的离线资产，下载后断网可用；运行期零联网、数据不出本机。"

## 目标

1. `src/main/modelManager.js`：清单拉取（可缓存）、下载（断点续传/进度/校验/删除）、双源扫描；
2. `components/ModelWizard.vue`：首次启动模型选择向导（3 次点击内完成，可跳过）；
3. `ModelHub.vue` 升级：本地已装列表 + 云端可下载列表 + 下载/删除/切换 + 自检报告；
4. electron-builder 双轨配置（A 不打包 models，B 保留 extraResources）；
5. 无模型时启动不阻塞（AI 功能显示"未就绪"，主流程照常）。

## 实现要点

- **断点续传**：用 `https` 模块 + `Range: bytes=`，`.part` 文件存进度；恢复时从已下字节续传；下载完成改名并校验 SHA-256，不符删 `.part` 报错可重试。
- **进度推送**：`event.sender.send('models:progress', { id, received, total, pct })`；渲染层节流更新 UI。
- **双源扫描**：`resources/models`（只读）+ `userData/models`（可写）；manifest.json 在 userData/models 登记已下载档位（版本/哈希/时间）；扫描时两处合并，冲突以 userData 为准（用户后来下载的更新）。
- **无模型降级**：`llm:status` 在无已装模型时返回 `state:'unavailable'` 或明确 `error:'未安装模型'`；渲染层 AI 叙述自动回退模板（现有降级链已支持，保持）。
- **向导触发**：`initStore` 后检测 `!registry.hasInstalled()` 且非 Electron 打包环境跳过；向导可"跳过"，稍后在模型中心装。
- **清单 URL 配置**：`models.json` 的 URL 做成数组（主源 + 备用镜像）；manifest 拉取失败 → 界面显示"离线，仅显示已装模型"。
- **打包**：electron-builder `extraResources` 条件化——提供 `npm run electron:build:online`（去掉 models）与 `electron:build:offline`（保留）。模型文件路径在打包配置里引用 `resources/models`。
- 铁律：下载只发生在**用户明确点击下载时**（一次性）；运行期无任何自动联网拉取（清单可启动时静默拉取但失败不阻塞、不重试轰炸——或做成仅向导/模型中心页面手动刷新）。

## 验收标准

1. 在线安装包构建成功，安装后体积 ~150MB 量级；无模型可正常进入工作台，AI 功能显示"未就绪/降级"；
2. 向导：选择档位 → 下载（进度显示）→ 校验 → 自检 → "可断网使用"；中途关应用再开可续传；
3. 断网后模型可用（加载/生成/自检正常）；
4. 模型中心：下载、删除（释放空间）、切换档位均正常；`llm-verify.json` 自检报告可展示；
5. 离线包（B）构建后内置 0.5B 开箱即用，不弹向导；
6. `npm run verify` 全绿（e2e 需适配：无模型环境下 AI 相关断言按降级路径断言）。

## 注意

- 下载源具体地址由你方提供（建议对象存储，支持 Range）；任务中先用占位 URL + 注释说明，**不要伪造真实 URL**。
- 不要在用户未确认时自动下载模型（隐私/流量）；一切以用户点击为准。
- 若 e2e 环境无模型文件，AI 相关 e2e 按现有降级路径跑，不要为过测试而改断言口径。

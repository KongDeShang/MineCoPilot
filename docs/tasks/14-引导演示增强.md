# 任务 14：引导演示增强（多路线 + 自动演示）

## 背景

- 现状：`src/renderer/src/utils/demoTour.js`（11KB）实现**单条 12 步主线**（看板→台账→病历→工单→AI 助手→规程库→复诊→本地模型），用 driver.js（`components/` 里按需加载，`styles/driverTheme.css` 有主题覆盖）跨路由遮罩高亮，支持前进/后退/退出。入口在右上角"引导演示"。
- 目标：升级为**多套演示路线 + 路线配置化（JSON）+ 自动演示模式**，让演示不再依赖讲解人节奏；路线可自定义（开发者/演示前配置，不改代码）。
- 依赖：任务 10 大屏模式（本任务可加"大屏线"路线步骤，若无则跳过该步）。

## 目标

1. `demoTour.js` 重构为「路线解析器 + 播放器」：路线 = JSON 配置（步骤：路由 + 高亮选择器 + 气泡文案 + 动作）；
2. 内置多路线：主线（现有 12 步保留）、AI 能力线（模型中心→AI 助手→口述/OCR→纪要）、大屏线（进入大屏→看板→退出）；
3. 自动演示模式：自动前进（可配置每步停留时长）、进度条、暂停/继续；
4. 演示工具条：悬浮"上一步/下一步/计时/重置/退出"。

## 实现要点

- **路线 JSON 结构**：
  ```js
  { id, name, steps: [
    { route: '/dashboard', target: '.focus-card', title, content, waitFor: 800, action: 'click'|'none', autoAdvance: true }
  ]}
  ```
  - `waitFor`：进入路由后等待渲染的毫秒数（页面异步数据加载完再高亮，避免高亮空元素——README 已有教训：自动演示的异步等待是重点）；
  - `target` 用 CSS 选择器，找不到时跳过该步并记录警告（不让演示卡死）。
- **自动演示**：每步停留默认 3s（可配），自动点下一步；暂停/继续按钮；进度条显示 n/N。
- **手动模式**：现有前进/后退/退出交互保留（评委自行走查）。
- **路线选择入口**：右上角"引导演示"改为下拉：主线 / AI 能力线 / 大屏线；大屏线需任务 10 已上线，否则该路线标注"待上线"。
- **工具条**：悬浮右下角（driver.js 遮罩之上），44px 触控目标，Esc 退出。

## 验收标准

1. 三条路线均可播放；步骤高亮元素正确出现（异步等待生效，不出现"高亮空白"）；
2. 自动演示可暂停/继续/重置；进度条正确；
3. 手动前进/后退/退出与升级前行为一致（主线体验不回退）；
4. 找不到选择器时优雅跳过并 console.warn，不白屏不卡死；
5. `npm run lint` 0 错；`npm run e2e` 全过（可加 1 条：进入引导→完成第一步→退出）。

## 注意

- 演示路线是**演示层**，不得触发真实写库动作（演示数据除外——现有主线已有此约束，保持）。
- 不引新库（driver.js 已有）；不改变 12 步主线的既有文案与顺序（评委可能已看过旧版，保持一致更稳）。
